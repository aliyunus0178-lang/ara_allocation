# 6a. Status Lifecycle
**Doc ID:** SRS-ARA-06a | **Parent:** [README.md](../README.md)

**ARA / Responsibility status:**
Active, Inactive, Suspended, On Leave, Pending Approval, Expired

**Preference submission status:**
Pending, Auto-Assigned (Tentative), Auto-Assigned (Final), Rejected,
Withdrawn

**Session assignment status:**
Unassigned, Tentatively Assigned, Confirmed, ARA Assignment Required
(unresolved)

Status transitions shall be recorded with a timestamp and, where
applicable, the triggering user or process (batch engine, real-time
engine, or administrator).
