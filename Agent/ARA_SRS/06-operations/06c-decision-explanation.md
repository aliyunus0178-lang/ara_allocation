# 6c. Assignment Decision Explanation
**Doc ID:** SRS-ARA-06c | **Parent:** [README.md](../README.md)

For every automatic assignment (batch or real-time), the system shall
store and display the reasons, e.g.:

```
ASSIGNMENT RESULT
Course: CSEg 1104 Lab | Section 1 | Group 1
Room: B-510-R05
Assigned ARA: ARA-001

Reasons:
✓ Responsible for laboratory block B-510
✓ Selected CSEg 1104 as Preference 1
✓ Qualified for CSEg 1104
✓ Available during scheduled period
✓ No timetable conflict
✓ Workload within limit
```

The administrator shall be able to view these reasons for any
assignment, tentative or final.
